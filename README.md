# NurseRoster — Nursing Roster Management

Arabic RTL Laravel/MySQL nursing shift scheduling project (MVP).

## Roles
- Nurse: submit monthly shift preferences.
- Manager: review requests, edit and approve final roster.

## Shift codes
- `E`: Morning
- `N`: Night
- `8`: Eight-hour shift
- `#`: Day off

## Project status
This repository is being populated. The Laravel application is **not yet deployed or production-tested**. Do not use it for live hospital scheduling until installation, authentication, authorization, and end-to-end testing are completed.

## Privacy
Do not commit actual staff spreadsheets, passwords, `.env`, or other confidential employee data.
